# 工具箱导航图标设计

## 背景

工具箱导航项当前使用 `Icons.handyman_outlined`，与建造导航项重复，导致两个入口难以通过图形快速区分。工具箱页面以后还会容纳舰队导出之外的其他工具，因此图标需要表达「多个工具组成的集合」。

## 设计

- 将工具箱导航项的图标替换为 `Icons.widgets_outlined`。
- 保留现有导航项的标签、顺序、页面索引和点击行为。
- 保留导航按钮现有的图标尺寸、颜色、间距以及选中态样式。
- 不调整建造、远征或其他导航项的图标。

## 选择理由

`Widgets` 图标由多个模块组成，能表达工具集合，也不会与现有的舰队、远征、入渠、建造、任务、战果、航海日志、装备和设置图标混淆。相比 `Category`，它更像一个功能集合；相比 `Extension`，它不会让用户误以为该入口只用于插件管理。

## 测试

- 导航渲染后，工具箱按钮包含 `Icons.widgets_outlined`。
- 工具箱按钮不再包含 `Icons.handyman_outlined`。
- 建造按钮继续使用 `Icons.handyman_outlined`，避免测试仅凭页面上的图标总数产生误判。
- 现有工具箱跳转测试继续通过，确认行为未改变。

## 非目标

- 不引入自定义图片或 SVG 资源。
- 不修改工具箱页面内部 UI。
- 不调整导航布局或其他功能入口。
