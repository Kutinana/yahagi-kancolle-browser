# 未持有装备扁平列表设计

## 目标

让“持有一览 → 未持有 → 装备”与未持有舰娘采用一致的扁平浏览方式，移除重复统计和需要逐组展开的操作。

## 界面方案

- 删除装备列表上方“显示 X 件未持有装备”汇总行；数量继续由顶部通用筛选栏的“筛选结果”提供。
- 删除“舰上攻击机（18）”一类装备类型折叠标题及其展开、收起能力。
- 将筛选后的全部未持有装备卡按现有排序直接连续排列。
- 使用与未持有舰娘相同的 `SingleChildScrollView`、边距和 `Wrap` 间距，保持页面观感一致并允许卡片自动换行。
- 每张装备卡内部保持现状，继续显示装备名称和装备类型等已有信息。
- 顶部装备分类筛选按钮、筛选结果数量及分类记忆行为均保持不变。

## 数据与交互

- 不修改 `UnownedInventoryProjection` 的未持有判定、过滤或排序逻辑。
- `_UnownedEquipmentView` 直接消费筛选后的 `UnownedEquipmentRow` 列表，不再按 `typeId` 二次分组。
- 空结果沿用当前空白列表表现，不新增空状态或提示。

## 验证

- 组件测试确认未持有装备视图不存在 `unowned-equipment-summary`。
- 组件测试确认未持有装备视图不存在 `ExpansionTile` 和装备类型分组标题。
- 组件测试确认筛选结果数量仍由顶部筛选栏正确显示。
- 组件测试确认筛选后的装备卡仍按投影顺序渲染，并在窄屏下无布局溢出。
- 运行持有一览相关测试、静态分析和完整测试集。
