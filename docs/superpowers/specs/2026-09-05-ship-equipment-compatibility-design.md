# 舰娘可装备装备抽屉设计

## 背景

现有装备库已支持从某件持有或未持有装备查看可装备的舰娘。本次增加反向查询：从某个持有舰娘或未持有舰娘形态查看其可装备的装备。

本功能复用现有装备适配规则和右侧抽屉交互，不新增数据库，不改变普通槽或增设栏的判定结果。

## 已选方案

采用「右侧镜像抽屉」方案：

- 持有舰娘表格与未持有舰娘卡片都可点击。
- 页面只保存当前选中的舰娘主数据 ID，右侧渲染一个共用的舰娘装备适配抽屉。
- 抽屉的宽度、层级、紧凑按钮、二级筛选窗口和整体滚动方式与现有「装备 → 舰娘」抽屉保持一致。

没有采用居中弹窗或独立详情页，因为两者会破坏已建立的双向查询交互。

## 入口与标题

### 持有舰娘

点击持有舰娘表格的任意整行，打开对应舰娘形态的抽屉。标题区显示舰娘头像、名称、舰种和该实例的等级。适配判定只使用舰娘主数据形态，实例等级仅用于帮助用户识别点击的舰娘。

### 未持有舰娘

点击未持有舰娘卡片，打开该舰娘形态的同一抽屉。标题区显示头像、名称和舰种，不显示虚构等级。

点击另一个舰娘行或卡片时，抽屉直接替换为新舰娘的内容。

## 抽屉内容

### 持有与全部

- 「持有装备」显示玩家当前至少持有 1 个实例，且该舰娘能装备的装备主数据。
- 「全部装备」显示游戏主数据中该舰娘能装备的全部有效装备。
- 同一装备只显示 1 张卡片。持有范围内在卡片右侧显示「持有 X3」等数量，并保持右对齐。
- 抽屉页签的数量表示当前舰娘可装备的装备种类数，不是装备实例总数。

### 分类与分组

筛选二级窗口直接复用当前装备库的 `EquipmentInventoryCategory`：

- 全部
- 主炮
- 副炮／高角炮
- 机枪
- 鱼雷／甲标
- 舰载机
- 水上机
- 陆航
- 对潜
- 电探
- 登陆／运输
- 辅助／其他

点击分类后立即生效，关闭二级窗口即可返回结果；窗口不放「重置」和「完成」按钮。

结果列表再按游戏主数据中的具体装备类型分组。每组先显示「中口径主炮」「水上侦察机」等标题，然后显示该类型下的装备卡片。卡片内不重复显示组标题。

### 搜索与槽位

- 搜索按钮打开与现有抽屉一致的二级输入窗口，输入装备名称并确认后过滤。
- 「全部槽位 / 普通槽 / 增设栏」直接复用 `EquipmentCompatibilityService` 的判定。
- 卡片右侧显示「普通槽」「增设栏」或「普通槽＋增设栏」。若特殊增设栏规则要求最低改修等级，继续显示该门槛。

## 数据流

`EquipmentCompatibilityService.resolve`已同时接收舰娘主数据 ID 与装备主数据 ID。反向查询无需改变规则，只需固定舰娘 ID，遍历有效装备主数据，保留 `canEquip` 为真的结果。

新的舰娘装备适配投影负责：

1. 按装备主数据 ID 汇总玩家的持有数量。
2. 过滤内部或无效装备主数据。
3. 通过 `EquipmentCompatibilityService` 判定普通槽与增设栏。
4. 应用持有范围、现有装备大类、名称搜索和槽位筛选。
5. 按具体装备类型分组，并按官方排序号和主数据 ID 稳定排序。

## 状态边界

- 点击关闭按钮、返回键或 `Esc` 时关闭抽屉。
- 切换「持有 / 未持有」或「舰娘 / 装备」时关闭抽屉。
- 在持有舰娘范围内，若被点击的舰娘实例消失，关闭抽屉。
- 在未持有舰娘范围内，若对应舰娘家族变为已持有，卡片消失并关闭抽屉。
- 舰娘或装备主数据、持有装备或适配规则更新时，保持抽屉打开并刷新结果，前提是当前舰娘仍属于当前范围。
- 规则数据未准备好时，显示与现有抽屉一致的等待提示。

## 组件边界

- `ShipEquipmentCompatibilityProjection`：负责反向投影、持有数量、过滤、分组和稳定排序。
- `ShipEquipmentCompatibilityDrawer`：负责镜像抽屉、二级分类窗口、搜索窗口和装备分组卡片。
- `OwnedInventoryPage`：管理选中舰娘、两种方向抽屉的互斥显示，以及页签切换和数据更新时的状态清理。
- `_ShipInventoryTable`、`_UnownedShipCard`：只向页面提交舰娘选择，不包含适配规则。
- `EquipmentCompatibilityService`：保持为唯一的槽位判定来源。

## 测试要求

- 投影单元测试覆盖持有与全部范围、现有装备分类、搜索、普通槽与增设栏筛选、持有数量、具体类型分组和排序。
- Widget 测试覆盖持有舰娘行和未持有舰娘卡片的打开行为。
- Widget 测试验证标题信息、「持有 X3」右对齐、具体类型分组、现有分类二级窗口不含「重置 / 完成」、搜索和槽位筛选。
- Widget 测试覆盖替换舰娘、关闭按钮、`Esc`、页签切换和当前舰娘离开当前范围时的关闭行为。
- 原「装备 → 舰娘」抽屉的打开、替换、关闭和实时刷新行为不回归。

实现完成后运行新投影单元测试、库存页 Widget 测试、变更文件静态分析和 `git diff --check`。按用户要求不构建 Debug APK，不操作用户的热重载会话。
