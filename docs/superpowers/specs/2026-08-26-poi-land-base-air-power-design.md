# POI 陆航制空公式同步设计

## 基准

以本地 POI 源码参考提交 `10d2b124335face321e58cd695022502561bedc5` 中的 `getTyku` 为计算基准，不继续沿用当前项目复制的旧版 POI 公式。

## 计算规则

- 纳入 POI 当前支持的制空机种：`6、7、8、11、26、45、47、48、53、56、57、58`，其中 `26` 仅在对空大于零时计入；陆航出击或防空时还纳入可部署侦察机 `10、41、49` 的自身制空。
- 每槽使用当前搭载数、装备对空、改修对空、局战迎击/对爆、熟练度类别加成与内部熟练度范围计算，并在每槽分别向下取整后求和。
- 改修对空按 POI 的机种、装备 ID 和线性/平方根规则计算，包括 `486/487` 的特殊系数以及指定爆战列表。
- 基地侦察倍率取所有侦察机中的最高值；完成逐槽求和后乘倍率并再次向下取整。
- 输出继续保留最小值和最大值；首页在范围不唯一时显示“最小值+”。

## 非目标

- 不修改舰队制空公式。
- 不修改陆基简报 UI、行动映射、血量或疲劳逻辑。
- 不执行热重载或 Debug 打包。

## 验证

将 POI 的代表性样例移植到 `test/land_base_air_power_test.dart`，覆盖喷式战斗机、大型陆上机、陆攻平方根改修、低对空局战改修、陆侦自身制空与侦察倍率，以及不应获得制空改修的普通舰爆/舰攻/水爆。
