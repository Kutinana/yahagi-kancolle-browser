# 开发功能导航迁移设计

## 目标

将现有装备开发工作台从“工具箱”移动到“建造”单元，建造单元顶部模式顺序固定为“建造 → 开发 → 改修”。入口文案缩短为“开发”，开发工作台的页面、计算逻辑、数据仓库与选择缓存保持不变。

## 设计

- `ConstructionCenterMode` 增加 `development`，枚举顺序即界面顺序。
- 建造中心在 `development` 模式渲染现有 `EquipmentDevelopmentPage`，继续注入现有 `DevelopmentRepository`。
- 工具箱恢复为单一“舰队导出”页面，并移除不再需要的二级模式切换。
- 建造模式切换使用独立的本地化“开发”文案，不修改工作台内部标题。

## 验收

- 建造顶部依次显示“建造、开发、改修”，点击“开发”进入原装备开发工作台。
- 工具箱不再显示“装备开发”入口，只保留舰队导出功能。
- 目标装备等工作台状态仍由原有持久化存储负责，迁移不改变其行为。
