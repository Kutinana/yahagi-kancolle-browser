# 竖屏工作区与“关于”页响应式修复设计

## 目标

在竖屏和展开折叠屏的上下布局中，让游戏画面使用完整可用宽度；工作区导航栏只占据下方功能区的高度。修复“关于”页在窄宽度下的横向溢出。

## 工作区布局

- 横屏左右布局保持现状：导航栏贯穿工作区高度，游戏与信息面板横向排列。
- 竖屏或近方形展开折叠屏采用上下布局时：游戏画面位于顶部并占满工作区宽度。
- 下方由固定宽度导航栏与信息面板组成一行；导航栏顶部、底部与信息面板可见区域对齐。
- 导航按钮尺寸、顺序、拖动排序、徽标和点击行为保持不变；内容超过高度时沿用导航列表滚动能力。
- 非游戏工作区继续使用整高导航栏，避免改变其他页面的既有空间结构。

## “关于”页布局

- 宽度充足时保留头像、名称/版本和操作按钮的横向布局。
- 窄屏时将身份信息与操作区分行；操作按钮使用可换行布局。
- 极窄宽度下按钮纵向排列并使用可用宽度，不缩小文字，也不引入横向滚动。
- 外部链接、检查更新、免责声明和版本展示逻辑保持不变。

## 验证

- Widget 测试验证竖屏/近方形窗口中游戏宽度不再被导航栏扣减，导航栏和信息面板垂直边界一致。
- Widget 测试验证横屏既有布局不变。
- Widget 测试在截图对应的窄宽度下渲染“关于”内容且没有 Flutter overflow 异常，并确认两个操作仍可访问。
- 在连接的 Android 折叠屏 Debug 会话中热重载，分别检查游戏页和“关于”页。
