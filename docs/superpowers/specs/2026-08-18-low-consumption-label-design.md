# 帧率“低耗”档位文案设计

## 目标

将帧率设置第二档的中文名称从“省电/省電”调整为“低耗”，使名称更准确地表达该档位通过固定 30 FPS 降低整体负载，而不把它误解为 Android 系统省电开关。

## 用户可见文案

- 简体中文：`低耗`
- 繁体中文：`低耗`
- 日文：保持 `省電`

自动档描述中的“系统开启省电/系統開啟省電”和日文中的“省電力モード”保持不变；这些文字指 Android 系统状态，不是帧率档位名称。

## 实现边界

- 只修改本地化资源及其生成代码。
- 保持 `gameFrameRatePowerSaving` 本地化键不变。
- 保持 `GameFrameRateMode.stable30`、持久化 wire value `stable30` 和 30 FPS 行为不变。
- 不修改自动、低耗、高刷三档的帧率策略。

## 测试与审计

- 先将界面测试的简中、繁中预期改为“低耗”，确认测试因旧文案而失败。
- 生成本地化代码后，确认相关界面测试通过。
- 因简中与繁中使用相同术语，将 `gameFrameRatePowerSaving` 登记为已审查的跨中文区域相同术语。
- 运行本地化资源审计，确认资源键、生成代码和术语审计均通过。

## 成功标准

- 简中和繁中界面显示“自动 / 低耗 / 高刷”。
- 日文界面显示“自動 / 省電 / 高リフレッシュレート”。
- 现有用户设置无需迁移，档位行为没有变化。
