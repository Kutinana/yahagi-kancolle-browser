# 通知设置下拉菜单改造设计

## 目标

压缩通知设置中提醒时机选项的横向占用，统一使用战斗设置中
“大破进击保护”的下拉菜单交互，并清理通知设置文案中的英文括注和
英文时间单位。

## 界面结构

- 远征归还、入渠修复和泊地修理各占一行。
- 每行从左到右依次为：通知类型名称、当前选项下拉菜单、启用开关。
- 下拉菜单放在开关左侧，三行使用一致的菜单宽度、间距和垂直对齐。
- 名称区域使用 `Expanded`，避免长文案挤压右侧控件。
- 禁用全局通知或当前类型时，下拉菜单同步禁用；开关行为保持不变。

## 选项与数据

- 远征归还：准点、提前 30 秒、提前 60 秒、提前 2 分钟。
- 入渠修复：准点、提前 60 秒。
- 泊地修理：满 20 分钟首轮、全部修满、两个阶段都提醒。
- 继续调用现有 `NotificationSettingsController` 方法，不改变持久化格式。

## 文案

- 简体中文、繁体中文和日文通知设置文案均删除 `(Type)`、
  `(Ongoing)`、`(Repair)` 等英文括注。
- 时间显示使用本地语言单位，例如“秒”“分钟”，不再出现 `s`、`m`、
  `min`。
- `NEW` 标记不属于说明性括注，本次保留。

## 验证

- Widget 测试确认三组 `SegmentedButton` 被下拉菜单替代。
- 测试确认菜单位于对应开关左侧并能更新控制器设置。
- 本地化审计确认通知设置目标文案不再包含英文括注和英文时间单位。
- 运行 Flutter 测试与 Android debug APK 构建。
