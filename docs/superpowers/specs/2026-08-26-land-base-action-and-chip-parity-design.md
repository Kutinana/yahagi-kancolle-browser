# 陆航行动映射与胶囊尺寸统一设计

## 目标

修正陆航退避／休息显示反转，并使基地名、行动、制空与航程胶囊采用首页舰娘状态胶囊的尺寸和字体度量。

## 行动映射

- `0`：待机
- `1`：出击
- `2`：防空
- `3`：退避，灰色
- `4`：休息，绿色

API 读取与状态存储保持不变，仅修正展示标签和颜色。

## 胶囊尺寸

陆航三类胶囊统一采用首页舰娘 `MiniBadge` 的尺寸度量：水平内边距 4、垂直内边距 1、圆角 4、字体 8、字重 700，并取消陆航专用固定高度和 `height: 1` 行高。保留陆航现有语义颜色和背景透明度。

## 范围

飞机槽位、搭载数量、HP、标题、海域标题以及其他页面的胶囊不变。

## 验证

- 测试 `3` 显示退避灰色、`4` 显示休息绿色。
- 测试陆航基地名、行动、制空胶囊与首页舰娘 `MiniBadge` 高度一致且字体均为 8。
- 运行陆航与首页编队相关回归测试并热重载实机。
