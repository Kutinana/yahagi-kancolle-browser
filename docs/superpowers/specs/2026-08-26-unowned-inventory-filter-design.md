# 未持有一览顶部筛选设计

## 目标

未持有舰娘与未持有装备页复用持有一览现有的顶部筛选条，减少展开、收起舰种或装备类型分组的操作成本。筛选条的视觉、标签、结果计数和横向滚动行为均与持有页一致。

## 方案选择

采用“复用现有分类和筛选组件”的方案：

- 舰娘使用 `ShipInventoryCategory`：全部、BB/BC、CV/CVL、CA、CL、DD、DE、SS、AV/AO/AS…。
- 装备使用 `EquipmentInventoryCategory`：全部、主炮、副炮/高角炮、机枪、鱼雷、舰载机、水上机、陆航、反潜、雷达、登陆/运输、辅助。
- 不新增动态舰种按钮，也不把每个折叠分组提升为筛选按钮，避免按钮数量随母数据变化。

## 交互

1. 切到“未持有”时，顶部立即显示与当前“舰娘/装备”页对应的筛选条。
2. 选择分类后先过滤未持有卡片，再按舰种或装备类型建立下方折叠分组；空分组不显示。
3. “筛选结果”显示过滤后的卡片数量。装备结果按未持有装备条目计数，不按折叠分组计数。
4. 舰娘排除勾选与筛选条件相互独立；切换分类不会修改或清空排除状态。
5. 在“持有/未持有”和“舰娘/装备”之间切换时，各自保留最后一次选择的分类。
6. 未持有筛选条不显示持有页的“恢复默认排序”按钮，因为未持有页没有可编辑排序状态。

## 实现边界

- 把舰娘分类判定提取成可供持有与未持有投影共用的纯函数，避免复制舰种 ID 规则。
- `UnownedInventoryProjection` 接受可选分类并返回过滤后的舰系或装备集合。
- `OwnedInventoryPage` 在未持有模式下复用 `_FilterStrip`，不新增搜索框。
- 不改变新舰提醒触发、排除存储或通知逻辑。

## 测试

- 投影测试覆盖舰娘分类、装备分类、空分组和结果数量。
- Widget 测试覆盖未持有舰娘及装备顶部筛选按钮、点击过滤、排除状态保持和无搜索框。
- 回归运行持有一览、未持有视图、本地化契约及完整 Flutter 测试。
