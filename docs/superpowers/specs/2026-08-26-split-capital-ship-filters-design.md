# 主力舰舰种筛选拆分设计

## 目标

将持有与未持有舰娘筛选栏中的 `BB/BC` 和 `CV/CVL` 拆成四个独立按钮，便于分别查看战舰、巡洋战舰、正规空母与轻空母，同时保持其他布局和行为不变。

## 分类映射

- `BB`：舰种 ID `9、10、12`，覆盖战舰、航空战舰和超弩级战舰。
- `BC`：舰种 ID `8`，覆盖巡洋战舰／高速战舰类。
- `CV`：舰种 ID `11、18`，覆盖正规空母和装甲空母。
- `CVL`：舰种 ID `7`，覆盖轻空母。
- 原有 `CA`、`CL`、`DD`、`DE`、`SS` 和支援舰分类映射保持不变。

## 筛选栏

- 按钮顺序为：`全部 → BB → BC → CV → CVL → CA → CL → DD → DE → SS → AV/AO/AS…`。
- 持有舰娘与未持有舰娘使用同一套分类枚举、标签和匹配函数。
- 筛选栏继续保持 28px 高、单行横向滚动、原有按钮样式与间距，不换行。
- 回转图标仍位于全部舰种按钮之后、“筛选结果”之前。

## 不变范围

- 不修改舰娘和装备卡片布局。
- 不修改持有列表排序、未持有提醒排除、筛选结果及已排除计数逻辑。
- 不修改装备筛选分类。
- 不增加新的本地化资源；四个按钮继续使用舰种缩写。

## 验证

- 投影测试分别验证 `BB`、`BC`、`CV`、`CVL` 的舰种 ID 边界，确保四组互不重叠且合计覆盖旧分组。
- 未持有投影测试确认四个分类使用同一匹配规则。
- 组件测试确认持有与未持有筛选栏均按指定顺序显示四个按钮，旧合并按钮不再存在。
- 组件测试确认筛选栏高度、单行横向滚动和回转图标位置保持不变。
- 运行持有一览相关测试、静态分析和完整测试集。
