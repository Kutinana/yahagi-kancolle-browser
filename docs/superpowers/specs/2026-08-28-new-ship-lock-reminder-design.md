# 新舰上锁提醒文案设计

## 目标

用户获得此前未持有且未被排除的舰娘时，在现有提醒正文中追加上锁提示，降低新舰误拆解或误消耗的风险。

## 方案选择

考虑以下方案：

1. 仅在应用内弹窗追加提示。系统通知仍只显示舰名，但两处文案不一致。
2. 在系统通知与应用内弹窗中统一追加提示。信息一致，用户在后台也能看到完整提醒。
3. 将提示加入标题。标题会变长，系统通知可能截断舰名或安全提示。

采用方案 2。

## 展示规则

- 标题保持「发现未持有舰娘」。
- 正文格式为「{舰名列表}，请不要忘记上锁」。
- 多艘舰娘继续使用顿号分隔，例如「雪风、岛风，请不要忘记上锁」。
- 无法解析舰名时继续使用现有回退名称，例如「舰娘 No.123，请不要忘记上锁」。
- 系统通知与应用内弹窗使用同一正文格式。
- 日文与繁体中文提供对应的本地化文案，不在业务代码中硬编码中文。

## 范围

本次只调整提醒正文，不改变新舰检测、排除名单、事件去重、战斗掉落延迟发布、通知权限或震动行为。

## 测试

- 验证单艘舰娘的系统通知正文包含上锁提示。
- 验证应用内弹窗使用本地化后的完整正文。
- 验证多艘舰娘与舰名回退仍按原规则生成。
