# noro6 国内镜像导出设计

## 背景

noro6 官方站托管在 GitHub Pages，部分中国大陆网络环境可能无法稳定访问。舰娘百科提供国内镜像 `https://noro6.kcwiki.cn/`，该镜像与官方站使用相同的 `#import:` 导入协议。

## 交互设计

舰队导出页面的外部工具按钮顺序调整为：

1. 导出至 noro6
2. 导出至 noro6（国内镜像）
3. 导出至 Jervis

国内镜像按钮与其他外部工具按钮使用相同的样式、启用条件、系统浏览器打开方式和失败提示。没有母港数据时，三个按钮均保持禁用。

## 导出设计

- 在 `ExternalFleetTool` 中增加独立的 `noro6Mirror` 目标。
- 官方站与国内镜像共用同一个 noro6 导入载荷生成函数。
- 官方站地址保持为 `https://noro6.github.io/kc-web/#import:<payload>`。
- 国内镜像地址为 `https://noro6.kcwiki.cn/#import:<payload>`。
- 两个地址的 `<payload>` 必须逐字相同，包含当前舰队、全部舰娘和全部装备。
- Jervis 的 `predeck` 查询参数逻辑保持不变。

## 本地化

新增国内镜像按钮文案：

- 简体中文：`导出至 noro6（国内镜像）`
- 繁体中文：`匯出至 noro6（中國鏡像）`
- 日文：`noro6（中国向けミラー）へエクスポート`

## 测试

- URI 单元测试验证镜像使用 HTTPS、主机为 `noro6.kcwiki.cn`、路径为 `/`，并包含 `#import:`。
- URI 单元测试验证官方站与镜像站解码后的导入载荷完全相同。
- Widget 测试验证新按钮位于官方 noro6 与 Jervis 按钮之间。
- Widget 测试点击镜像按钮后，收到的 URI 使用镜像域名，并保留舰队、舰娘与装备数据。
- 等待母港数据时，新按钮保持禁用。

## 非目标

- 不自动检测用户网络或自动切换站点。
- 不改变官方 noro6 按钮的行为。
- 不在应用内嵌页面打开外部工具。
