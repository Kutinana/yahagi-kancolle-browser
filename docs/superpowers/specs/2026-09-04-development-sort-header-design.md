# 装备开发排序表头统一设计

## 目标

装备开发的“出货概率”和“可用公式”表格统一采用持有一览的排序提示视觉。

## 交互与视觉

- 当前排序列：标题文字与方向符号整体使用 `Color(0xffffc85a)`。
- 降序在标题后显示 `▼`，升序显示 `▲`。
- 非当前排序列使用普通表头颜色，不显示方向符号。
- 保留现有点击排序、数值列对齐、缓存排序字段和方向的行为。
- 移除“出货概率”列当前使用的前置 Material 上下箭头。

## 范围

仅调整 `development_output_table.dart` 和 `development_recipe_table.dart` 的排序表头呈现，并更新对应 Widget 测试。不调整数据排序算法、表格尺寸或其他页面。

## 验证

- 默认降序显示黄色 `最终概率 ▼` 与黄色 `出货率 ▼`。
- 点击后显示黄色 `最终概率 ▲` 或对应公式排序标题的 `▲`。
- 切换公式排序列后，旧列恢复普通标题，新列显示黄色方向符号。
