# 经验计算页面视觉统一设计

## 目标

将「工具箱 → 经验计算」页面重构为 Yahagi 现有的深色海军风格，使其与全局主题及同工具箱内其他页面保持一致。此次修改会重新组织布局和组件层级，但不改变计算逻辑、数据结构与持久化行为。

## 视觉方案

采用已确认的方案 C：在深海军蓝、灰蓝卡片与金色主强调色的基础上，同时重构布局与组件。

- 页面背景沿用应用的深海军蓝基底。
- 卡片使用比背景略亮的灰蓝色，边框降低亮度，避免现有高饱和蓝色造成割裂。
- 金色用于标题标识、步骤编号、当前选中项和主要操作。
- 青蓝色仅用于经验值、等级等数据内容，形成清晰的数据语义。
- 绿色表示完成或启用状态，红色表示删除、错误或未完成状态，橙色用于目标等级等辅助重点。
- 正文、次级文字和弱提示采用应用现有的浅灰蓝层级。

## 组件调整

### 页面与标题区

- 页面背景对齐全局 `scaffoldBackgroundColor`。
- 将标题图标由亮蓝渐变改为低调金色识别块。
- 移除页面特有的蓝色光晕，保留紧凑、清晰的标题层级。
- 标签、分隔线和说明文字改用统一的灰蓝与金色组合。

### 信息结构

- 宽屏采用「左侧设置、右侧结果」的双栏工作区：舰娘与目标、路线配置位于左侧，计算摘要与追踪操作位于右侧。
- 窄屏自动回落为单列，并保持「舰娘目标 → 路线 → 结果 → 追踪列表」的任务顺序。
- 将分散的标题、说明和步骤提示收敛为更短的区块标题，降低纵向占用。
- 路线节点使用统一的紧凑编辑卡，突出海域、点位、基础经验和倍率选择。
- 追踪列表作为独立的历史区块，宽屏使用表格，窄屏继续使用卡片，保持现有响应式能力。

### 卡片与输入控件

- 步骤卡片、路线卡片、结果卡片和追踪卡片使用同一组表面色、边框色和圆角。
- 下拉框、文本框与切换控件统一填充色、默认边框、聚焦边框及禁用态。
- 排名、旗舰、MVP、视图切换等选中态使用金色或对应语义色，未选中态维持低对比灰蓝。

### 数据与操作

- 经验值等主要数字保留青蓝数据色，但降低霓虹感。
- 「添加追踪」等主操作使用金色背景与深色前景。
- 删除操作继续使用红色，完成状态继续使用绿色。
- 结果 HUD 重排为核心数字优先的摘要面板，路线汇总及追踪表格统一信息层级，不删除现有字段。

## 实现边界

- 主要修改 `lib/src/toolbox/exp_calc/exp_calc_page.dart`。
- 可在该文件内集中定义页面专用颜色常量，减少散落的硬编码颜色，并便于后续维护。
- 可抽取页面内部的私有展示组件，降低单个构建方法复杂度；不新增跨模块抽象。
- 不修改经验计算模型、经验表、持久化存储、本地化资源或其他工具箱页面。
- 不引入新依赖，不执行 APK 打包或 debug 构建。
