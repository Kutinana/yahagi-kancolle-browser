# 战果三页正式接入设计

## 目标与范围

把已确认的浏览器 Demo 接入 Yahagi Flutter 正式工程，继续使用现有舰队 API 捕获、排名解密、战果日历与 SharedPreferences 档案，不引入演示假数据。战果入口拆成「战果信息」「战果日历」「战果计算」三页，并在平板横竖屏、方形折叠屏、手机横竖屏上保持 Demo 的阅读顺序和交互。

本次只交付开发代码、测试和 Android Debug 构建，不修改版本号、签名、发布目录，不构建 release、bundle 或正式 APK。

## 数据模型与迁移

- 奖励状态统一为 `deferred`、`planned`、`completed`。
  - 放置：黄色、`✕`，不计入预计值。
  - 计划：绿色、`✓`，计入预计值。
  - 完成：灰色、无图标，整枚胶囊中线贯穿，认为已含于当前战果，不重复加算。
- EO 的游戏地图清图信息自动写入完成态；所有 EO 与任务仍可手动循环三态。
- 兼容现有 `completedEoIds`、`completedQuestIds`：旧完成集合迁移为 `completed`，未知状态逐项回退为 `deferred`，日历、排名和身份数据不丢失。
- 新增并持久化目标战果、计算用当前战果、奖励状态、出击海域统计、收藏和隐藏状态。
- 出击统计由真实 API 自动累计：地图开始记一次出击，到达 Boss 记一次 Boss，Boss 战结算按 S/SS 或 A 分别累计；不统计演习。

## 页面与交互

### 战果信息

- 横屏和平板宽屏：左右等宽；左侧为服务器概况（上）和现有战果排名（下），右侧为出击海域统计。
- 竖屏与方形折叠屏：服务器概况、排名、出击统计纵向排列并允许页面滚动。
- 服务器概况显示服务器名称、当前战果和当前排名；服务器由捕获来源主机的 `wNN` 编号映射，未知时显示「未知服务器」。
- 排名设计沿用现有正式页，所有战果和变化值固定两位小数。
- 海域表固定列为「海域 / Boss / 出击 / S / A / 操作」。每条记录保持单行、中线对齐、统一字号；操作提供收藏和隐藏。隐藏记录可通过顶部开关重新显示。

### 战果日历

- 日历独占一页，沿用现有 6×7 月历、当日详情与本月累计。
- 所有战果显示两位小数；紧凑横屏压缩间距但不改变信息结构。

### 战果计算

- 横屏和平板宽屏使用 Demo 的 3∶7 左右布局；手机横屏与大平板比例一致。
- 竖屏与方形折叠屏按左侧概况、右侧任务矩阵顺序纵向滚动。
- 当前战果与目标战果可编辑并实时计算。左侧指标严格为三行两列：
  1. 已勾选 EO｜已勾选战果任务
  2. 剩余日数｜素战果
  3. 每日所需｜今日剩余
- `素战果 = 提督经验增加量 × 7 / 10000`；剩余日数按战果业务日到月末（含当天）计算；每日所需以 CLEAR 后尚欠目标值除以剩余日数；今日剩余以每日所需减去本地当天快照并限制为非负。
- 右侧分组为「EO 战果奖励」「季度战果任务」「年度战果任务」「单次战果任务」。年度包含 AL 作战（480）和机动部队决战（600）；单次包含「改装特务空母『Gambier Bay Mk.II』抜錨！」并以「火球炮」简称显示（800）。
- 说明文字为「EO·战果炮 CLEAR 后共计 … 战果（…% · 距离目标还差/已超出 … 战果）」；页脚显示计划 EO、计划任务与合计。所有战果固定两位小数。

## 错误处理与性能

- 损坏缓存返回空当月档案；单个未知奖励状态不影响其余数据读取。
- API 缺字段或顺序不完整时不伪造统计；新出击开始会替换未闭合的临时上下文。
- 状态更新继续走现有串行队列与帧通知合并，单次事件只持久化一次。
- 文本输入无法解析时保留上一次有效值；负值归零。
