# 后台通知完成状态设计

## 目标

远征、建造、入渠和疲劳恢复到达完成时间后，不再直接从常驻通知中消失。任务应转换为明确的“已完成”状态，同时发送一条普通高优先级完成通知。

本次继续直接在 `master` 上实现。手机重启后的提醒恢复仍不在范围内。

## 用户体验

任务进行中时，常驻概览显示倒计时和当前进度。

任务到时后：

- 常驻概览中的对应任务继续保留；
- 文案由倒计时切换为“已完成”；
- 进度条显示 100%；
- Android 同时发送一条普通完成通知，按系统允许的方式发声、振动并显示横幅；
- 普通完成通知一直保留，直到用户点击或手动划掉；
- 划掉普通完成通知不会移除常驻概览中的“已完成”任务。

任务只有在游戏返回新的权威状态、确认它已经被处理后，才从常驻概览移除。例如：

- 远征：舰队不再处于该远征；
- 建造：船坞不再处于该次建造；
- 入渠：渠位已空或不再修理该舰；
- 疲劳恢复：新的舰船状态表明该恢复任务已完成或目标发生变化。

玩家主动使用快速建造、快速修理等操作时，游戏状态更新本身即视为确认，旧任务应立即移除且不得补发过期通知。

## 状态模型

`OngoingNotificationItem` 增加明确的状态字段：

- `running`：显示倒计时和动态进度；
- `completed`：显示“已完成”和 100% 进度。

完成闹钟触发时，Android 原生层执行原子状态转换：

1. 发布普通完成通知；
2. 从持久化快照中移除已触发闹钟；
3. 将相同 `taskId` 的常驻项目改为 `completed`，而不是删除；
4. 重绘常驻概览。

预提醒和泊地修理阶段性提醒不会把任务标记为完成。

## Flutter 与原生层同步

Flutter 仍负责根据游戏数据生成完整目标快照，Android 负责在应用不运行时保存和推进通知状态。

为了避免应用重新打开后用旧缓存误删原生完成状态，Flutter 对“截止时间已过但权威游戏状态仍显示任务存在”的项目也生成 `completed` 状态。收到新的游戏 API 状态、确认任务已经结束后，下一份完整快照才会删除它。

这套规则适用于：

- 远征；
- 建造；
- 入渠；
- 自然疲劳恢复以及当前归入疲劳通知类型的刷闪完成任务。

## 明石泊地修理特殊规则

明石常驻通知不使用普通任务的剩余时间倒计时，而与游戏内明石计时器共用同一个计时锚点，显示正向累计修理时间，例如“已修理 18分35秒”。Flutter 页面和 Android 通知不得分别创建计时起点。

到达 20 分钟时：

- 发送普通阶段通知：“泊地修理已满 20 分钟，可返回母港结算”；
- 常驻项目继续保留；
- 正向累计时间继续运行；
- 状态文案切换为“首轮结算就绪”，而不是“已完成”。

启用“预计全部修复”提醒时，到达计算出的最终修复时间后：

- 发送普通完成通知；
- 常驻进度显示 100%；
- 状态显示“预计修理完成 · 等待母港确认”；
- 正向累计时间继续基于同一锚点展示，不另起计时。

返回母港刷新后，如果仍有符合条件的受损舰船，明石计时器按照现有游戏规则进入新的周期，通知随同一计时器更新；如果舰船已修好、明石被换下或舰队不再满足泊地修理条件，通知任务立即移除。

## 普通完成通知可靠性

接收器处理闹钟前重新确保通知渠道存在，避免冷进程启动时依赖 Activity 初始化。

完成通知使用独立于常驻概览的高重要性渠道、独立通知 ID、`CATEGORY_REMINDER` 和公开锁屏可见性。Android 8 及以上的横幅最终仍受用户对对应通知渠道的系统设置、勿扰模式及厂商策略控制；应用设置页应准确检查普通提醒渠道，而不只检查常驻概览渠道。

如果通知权限或渠道被关闭，状态转换仍要成功，常驻概览在权限恢复后可根据持久化快照重建。

## 边界条件

- 同一任务的完成闹钟重复投递时，只保留一条完成通知和一个完成项目；
- 多个任务同时完成时，每个任务产生独立普通通知，常驻概览显示多个“已完成”项目；
- 普通通知 ID 不得与常驻通知 ID 冲突；
- 新任务复用同一船坞、渠位或舰队时，新的截止时间和任务内容应覆盖旧完成状态；
- 应用进程被清理后，原生快照继续保存完成状态；
- 系统“强行停止”和手机重启仍遵循 Android 限制及本项目已确认的范围。

## 测试策略

Flutter 测试覆盖：

- 四类任务截止后仍生成 `completed` 常驻项目；
- 快速完成或权威状态清除后项目消失；
- 新任务可以替换同一位置的旧完成项目；
- 快照序列化包含任务状态。
- 明石通知与游戏内计时器使用相同锚点并显示正向累计时间；
- 明石 20 分钟提醒只进入“首轮结算就绪”，不会误标记为完成；
- 明石预计全部修复后进入“等待母港确认”。

Android 单元测试覆盖：

- 完成闹钟把 `running` 转换为 `completed`，不删除项目；
- 预提醒不会转换状态；
- 重复完成处理保持幂等；
- 快照 JSON 往返保留状态字段。
