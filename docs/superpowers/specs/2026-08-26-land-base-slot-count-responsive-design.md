# 陆航槽位搭载数量自适应设计

## 目标

提高展开折叠屏上陆航飞机槽位右上角搭载数量的可读性，同时保持普通屏幕现有效果。

## 响应规则

- 复用现有 `isNearSquareLargeDisplay(context)` 窗口分类，不判断设备型号。
- `nearSquareLarge` 窗口的搭载数量字号由 8 调整为 10。
- 其他窗口继续使用 8。

## 范围

- 只修改 `_LandBaseSquadronSlot` 右上角搭载数量的字号。
- 飞机图标、槽位尺寸、数量位置、数量背景、基地胶囊及其他文字均保持不变。

## 验证

- Widget 测试分别覆盖普通窗口与近方形大屏窗口。
- 验证普通窗口字号仍为 8，近方形大屏窗口字号为 10。
- 运行陆航简报与自适应布局相关回归测试，确认无溢出。
