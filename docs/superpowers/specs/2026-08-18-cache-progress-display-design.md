# 本地缓存进度精简显示设计

## 目标

简化本地缓存设置区的进度信息，减少不必要的技术状态，让玩家只关注已经下载的容量和完成百分比。

## 界面行为

- 已知清单总量时显示：`6.84 GB（84.2%）`。
- 清单总量未知时显示：`0.00 GB（--）`。
- 不再显示“缺失、损坏、过期”统计行。
- 保留“开始下载”“检查完整性”“补齐或修复”“清除本地缓存”按钮及其现有行为。

## 数据与逻辑

- `cachedBytes` 继续用于格式化已下载容量。
- `targetBytes` 只用于计算百分比，不直接显示。
- 百分比继续限制在 `0%` 到 `100%`。
- 原生缓存状态、清单生成、下载、完整性检查和修复逻辑不变。

## 测试

- 控制器测试覆盖已知总量和未知总量两种格式。
- 组件测试确认新文案存在，旧的分母格式和三项状态统计不存在。
- 运行缓存设置相关 Flutter 测试与 Debug APK 构建。
