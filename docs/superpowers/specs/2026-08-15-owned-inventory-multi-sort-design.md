# 持有一览多级排序设计

## 背景

持有一览目前只保留一个排序字段。用户点击新表头后，旧排序字段会被替换，无法表达“先按等级、等级相同再按火力、火力相同再按反潜”这类组合规则。

本次改动为舰娘持有一览增加可见、可编辑的多级排序。装备持有一览不在本次范围内。

## 目标

- 用户可以自由组合任意舰娘表格字段。
- 字段的首次点击顺序决定排序优先级。
- 每个排序字段可以独立切换升序或降序。
- 用户可以移除单个排序字段，也可以一键恢复默认排序。
- 当前排序优先级和方向始终显示在表头中。

## 排序状态

页面保存一个有序的排序条件列表。每个条件包含：

- 字段，例如等级、火力或反潜；
- 排序方向，即升序或降序。

默认列表只有一个条件：

```text
等级 ↓①
```

排序比较器按列表顺序逐项比较。只有上一级字段的值相同，才比较下一级字段。所有条件都相同时，按持有舰实例 ID 从小到大排列，保证结果稳定。

## 交互规则

### 点击表头

- 点击未在排序列表中的字段：将该字段追加到列表末尾，初始方向为降序。
- 点击已经在排序列表中的字段：切换该字段的升序或降序，优先级不变。
- 点击不会移除已有的其他排序条件。

例如依次点击等级、火力、反潜后，规则为：

```text
等级 ↓① → 火力 ↓② → 反潜 ↓③
```

### 长按表头

- 长按已在排序列表中的字段：移除该条件。
- 长按未加入排序列表的字段：不改变排序状态。
- 如果移除后列表为空，立即恢复默认的“等级降序”。

### 还原按钮

在“全部、BB/BC、CV/CVL……”舰种分类按钮所在行的末尾增加“还原”按钮。

点击“还原”后：

- 清除全部自定义排序条件；
- 恢复默认的“等级降序”；
- 保留当前舰种分类，不切换回“全部”。

## 表头展示

参与排序的表头显示方向箭头和从 `1` 开始的优先级编号，例如：

```text
等级 ↓①　火力 ↓②　反潜 ↑③
```

未参与排序的表头只显示字段名称。现有的选中颜色继续用于所有参与排序的表头，不只标记第一级。

## 数据与组件调整

- 用有序的排序条件列表替换页面中的单个 `_sortField` 和 `_descending` 状态。
- `OwnedInventoryProjection.shipRows` 接收排序条件列表，并逐级比较。
- `_ShipInventoryTable` 接收完整排序条件，为每个表头计算方向和优先级。
- `_SortableHeader` 增加长按回调，并展示优先级编号。
- 还原按钮只修改排序状态并清除舰娘列表缓存。

排序状态只在当前页面实例存活期间保留。本次不增加持久化设置。

## 边界行为

- 最多可加入当前表格支持的全部排序字段，不设置额外上限。
- 文本字段继续使用当前字符串比较规则。
- 数值、锁定状态和装备数量继续使用现有字段取值规则。
- 分类筛选变化不会清除排序列表。
- 舰娘数据刷新后，继续使用当前排序列表重新计算结果。

## 测试与验收

### 排序投影测试

- 依次使用等级、火力、反潜条件时，结果按优先级逐项比较。
- 每一级均支持升序和降序。
- 所有条件相同时，按持有舰实例 ID 从小到大排列。
- 空条件列表回退到等级降序。

### 页面交互测试

- 初始表头显示“等级 ↓①”。
- 点击未选择字段会追加优先级，不会替换已有条件。
- 再次点击已选择字段只切换方向。
- 长按表头移除对应条件。
- “还原”按钮恢复“等级 ↓①”，并保留当前舰种分类。
- 多个参与排序的表头均显示选中样式、方向和编号。

### 回归要求

- 原有舰种分类、横向滚动、冻结舰名列和装备持有一览行为不变。
- 持有一览相关组件测试和投影测试全部通过。
- Flutter 静态分析无新增问题。
