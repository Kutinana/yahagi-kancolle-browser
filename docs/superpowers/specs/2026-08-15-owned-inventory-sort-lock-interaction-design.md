# 持有一览锁定式多级排序设计

## 背景

现有多级排序会把每次点击的新字段追加到排序链末尾。默认等级排序始终占据第一优先级，因此用户点击火力或反潜后，列表通常没有明显变化。现有长按操作用于删除排序条件，也与「长按锁定当前排序」的原始操作预期不符。

本次调整将排序交互改为「点击临时排序、长按锁定优先级」。用户无需打开额外面板，即可在表头完成单列排序和多级排序。

## 目标

- 点击表头时立即看到该字段对列表顺序的影响。
- 通过长按建立或解除多级排序优先级，避免进入额外设置界面。
- 直接在表头显示锁定状态、升降序和优先级。
- 保留一键还原能力，并且不清除舰种筛选条件。

## 非目标

- 不增加 Excel 式弹窗或独立排序状态栏。
- 不支持拖动调整已锁定条件的优先级。
- 不支持通过拖动重新排列已锁定条件；解除后由系统自动补齐优先级。
- 不增加「满足先制反潜条件」等业务筛选规则。

## 状态模型

页面维护两类排序状态：

- **锁定条件列表：** 按锁定顺序保存，构成稳定的第一、第二等优先级。
- **临时条件：** 最多保存 1 项，排在全部锁定条件之后。点击其他未锁定字段时替换该项。

初始状态没有锁定条件，临时条件为等级降序。实际比较器按「锁定条件列表 → 临时条件 → 持有舰 ID 升序」依次比较。

## 交互规则

### 点击未锁定表头

- 没有锁定条件时，将临时条件替换为该字段，立即执行单列排序。
- 已有锁定条件时，将临时条件替换为该字段，并作为锁定条件之后的末级排序。
- 再次点击当前临时字段时，仅切换升序或降序。
- 首次选择一个新字段时，默认使用降序。

### 长按未锁定表头

- 长按当前临时字段时，将其追加到锁定条件列表末尾。
- 长按其他未锁定字段时，先用默认降序设为临时条件，再立即追加到锁定条件列表末尾。
- 锁定完成后清空临时条件，等待下一次点击选择末级排序。
- 每个字段最多出现 1 次，不允许重复锁定。

### 操作已锁定表头

- 点击已锁定字段时，只切换该字段的升序或降序。
- 长按已锁定字段时，只解除该字段的锁定。
- 被解除字段之后的锁定条件自动前移并重新编号，例如原来的 `②③` 变为 `①②`。
- 当前临时条件继续保留；它的末级优先级随锁定条件数量自动更新。
- 如果解除的是最后一个锁定条件，且存在临时条件，则临时条件继续作为普通单列排序，不再显示带圈优先级。
- 如果解除的是最后一个锁定条件，且不存在临时条件，则恢复为默认等级降序。

### 还原排序

点击筛选行末尾的还原图标按钮后：

- 清空全部锁定条件。
- 将临时条件恢复为等级降序。
- 保留当前舰种筛选条件。
- 保留当前舰娘或装备页签。
- 按钮使用逆时针还原图标，不显示「还原默认排序」文字；工具提示和无障碍标签仍使用本地化文案「还原默认排序」。

## 视觉反馈

- 临时排序字段使用黄色强调，显示方向，不显示锁图标。
- 已锁定字段使用蓝色强调，显示方向、带圈优先级和锁图标，例如 `反潜 ▼① 🔒`。
- 有锁定条件时，临时字段显示其末级优先级，例如 `火力 ▼②`。
- 没有锁定条件时，默认显示 `等级 ▼`，避免把未锁定状态误解为已固定的第一优先级。
- 还原按钮继续位于舰种筛选行末尾，使用现有深色背景、琥珀黄色（`#FFC85A`）逆时针还原图标。
- 图标尺寸约为 18–20 px，点击区域约为 32–36 px，并保留工具提示与屏幕阅读标签。

## 示例

1. 初始显示 `等级 ▼`，列表按等级降序排列。
2. 点击反潜，显示 `反潜 ▼`，列表立即按反潜降序排列。
3. 长按反潜，显示 `反潜 ▼① 🔒`，反潜成为第一优先级。
4. 点击火力，显示 `反潜 ▼① 🔒` 和 `火力 ▼②`，列表先按反潜、再按火力排列。
5. 长按火力，显示 `反潜 ▼① 🔒` 和 `火力 ▼② 🔒`。
6. 点击雷装，雷装成为临时第三优先级；改点装甲时，装甲替换雷装成为临时第三优先级。
7. 长按反潜解除第一优先级后，火力自动变为 `火力 ▼① 🔒`，装甲变为临时 `装甲 ▼②`。
8. 再长按火力解除最后一个锁定条件后，装甲继续作为普通单列排序，显示 `装甲 ▼`。
9. 点击还原图标，恢复为 `等级 ▼`。

## 边界处理

- 锁定条件存在但临时条件为空时，只使用锁定条件排序。
- 点击已锁定字段不会把它复制到临时条件中。
- 长按已锁定字段只移除该字段，不改变其他字段的相对先后顺序。
- 解除中间锁定条件后，后续锁定条件与临时条件的显示优先级连续前移。
- 解除最后一个锁定条件且没有临时条件时，回到默认等级降序，避免出现空排序链。
- 全部比较条件相同时，使用持有舰 ID 升序保证结果稳定。
- 字段值缺失时沿用现有投影层的兜底值，不在界面层增加特殊分支。

## 组件与数据流

- 页面状态保存锁定条件和临时条件，并将合成后的排序链传给投影层。
- 表头组件接收字段状态、方向、优先级和锁定标记；长按时根据当前锁定状态执行锁定或解除锁定。
- 投影层继续使用通用多条件比较器，不感知「锁定」或「临时」交互概念。
- 还原图标按钮只重置排序状态，不修改筛选状态。

## 测试要求

- 验证无锁定条件时，点击新字段会替换单列排序。
- 验证再次点击临时字段会切换方向。
- 验证长按临时字段会锁定并清空临时条件。
- 验证长按其他未锁定字段会以降序直接追加锁定。
- 验证锁定后点击新字段会建立临时末级排序。
- 验证点击已锁定字段只切换方向。
- 验证长按已锁定字段会解除该字段，并使后续优先级连续前移。
- 验证解除锁定时会保留临时排序，并更新其末级优先级。
- 验证解除最后一个锁定条件且存在临时条件时，临时条件变为无编号的单列排序。
- 验证解除最后一个锁定条件且不存在临时条件时，恢复默认等级降序。
- 验证点击其他未锁定字段只替换临时末级，不改变锁定链。
- 验证还原按钮只显示图标，同时具备本地化工具提示和无障碍标签。
- 验证点击还原图标后恢复等级降序并保留舰种筛选。
- 验证全部条件相同时仍按持有舰 ID 升序排列。
