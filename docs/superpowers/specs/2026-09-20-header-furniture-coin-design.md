# 顶部家具币资源胶囊设计

## 目标

在顶部资源栏中新增家具币资源胶囊。胶囊沿用现有资源项的尺寸、颜色、字体、提示和编辑交互，不引入新的视觉样式。

## 展示规则

- 资源 ID 使用 `furniture-coin`。
- 排列在「改修资材」之后、「家具箱（小）」之前。
- 默认隐藏，用户可在顶部资源筛选中启用。
- 已保存顶部资源顺序的旧用户会自动获得该资源项，并保持其余项目的相对顺序；新项插入指定位置。
- 已保存的可见项不自动加入家具币，避免改变旧用户的顶部布局。
- 已同步 `api_basic.api_fcoin` 时显示 `GameState.furnitureCoins`；尚未同步时显示 `—`。
- 标签使用「家具币」，并通过现有本地化映射显示对应语言文本。

## 图标

采用舰队 Collection 游戏客户端 `common_itemicons` 图集中的官方家具币图标。将目标帧提取为独立 PNG，放入现有 `assets/images/material/` 目录，由资源目录统一加载。

不复用家具箱图标，也不使用通用 Material 金币图标。

## 代码结构

- 扩展 `HeaderResourceSpec`，使资源值既可来自 `GameResourceType`、道具数量，也可来自家具币状态。
- 在 `headerResourceCatalog` 中注册家具币资源项。
- 在顶部资源顺序及默认可见项配置中加入家具币：进入完整顺序，但不进入默认可见列表。
- 在旧配置规范化逻辑中处理指定插入位置。
- 继续复用 `CompactResourceBar` 的展示、筛选、排序和持久化逻辑。

## 测试与验证

- 先增加失败测试，覆盖家具币数值、未同步占位符、官方图标路径和默认隐藏行为。
- 覆盖旧顺序配置迁移，确认家具币位于改修资材与家具箱（小）之间，且不改变旧可见项。
- 运行相关 Flutter 单元测试和静态分析。
- 在当前 DEBUG 运行会话中执行热重载，打开顶部资源筛选，启用家具币并检查图标、数值、顺序和胶囊样式。
- 本次不执行 APK、AAB 或其他发布/调试包构建。

## 范围外事项

- 不把家具币加入八项基础资源网格。
- 不把家具币加入资源趋势统计。
- 不修改家具币抓取与持久化逻辑；现有 `api_fcoin` 数据链路直接复用。
