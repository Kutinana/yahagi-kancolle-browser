# 通知远征编号与百分比设计

## 目标

常驻通知中的远征编号与游戏界面保持一致，并在启用“显示百分比”和“显示倒计时”时，将百分比稳定显示在倒计时左侧。

## 设计

- 远征标题复用 `expeditionDisplayId()`。优先采用母港数据中的 `displayNumber`，缺失时使用现有的 A/B/D/E 映射，最后才回退到数字 ID。
- 常驻通知仍使用一个 `Chronometer` 显示“百分比 + 倒计时”，不增加布局控件。Android `Chronometer` 的格式字符串中，字面百分号使用 `%%` 转义，例如 `53%%  %s` 最终显示为 `53%  10:09`。
- 关闭百分比时只显示倒计时；关闭倒计时但开启百分比时只显示百分比，保持现有设置语义。

## 测试

- Flutter 协调器测试覆盖任务 110 显示为 B1，并验证母港 `displayNumber` 优先。
- Kotlin 纯单元测试覆盖 Chronometer 格式字符串的百分号转义。
