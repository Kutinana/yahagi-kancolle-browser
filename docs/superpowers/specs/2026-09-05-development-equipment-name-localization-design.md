# 装备开发名称本地化设计

## 目标

装备开发页中的装备名称跟随当前界面语言，避免简体中文界面继续显示日文原名而产生字体不统一的观感。现有鸿蒙字体、字号、字重与布局保持不变。

## 方案

在装备开发快照的装备记录中加入 `names` 字段，保存 `zh`、`zh_Hant`、`ja` 三套名称。同步脚本从上游 `public/data/i18n/*/items.json` 读取对应翻译，快照构建器按装备 ID 写入名称；缺少翻译时回退到日文原名。

`DevelopmentEquipmentRecord` 提供按 `Locale` 取显示名称的接口。选择弹窗、目标装备标签和出货概率表格都调用同一接口。搜索会匹配原名及全部本地化名称，保证切换语言后仍可正常检索。

## 边界与错误处理

- 不修改游戏本身的装备主数据，也不影响持有一览等其他页面。
- 不进行机械简繁转换，避免舰船装备专有名词出错。
- 上游翻译文件缺少单条记录时使用日文原名，不阻断数据同步。
- 同步输入文件纳入来源哈希，确保快照可追溯。

## 验证

- 先增加快照构建器测试，证明三种语言名称会写入且缺失时正确回退。
- 增加数据模型与组件测试，覆盖简体、繁体、日文显示和多语言搜索。
- 运行装备开发测试、字体审计、静态分析，并构建 Debug APK；不安装。
