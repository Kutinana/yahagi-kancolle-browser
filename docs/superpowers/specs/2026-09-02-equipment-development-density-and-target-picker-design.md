# 装备开发表格密度与目标装备选择器优化设计

## 背景

开发工作台已经完成计算器与开发公式分栏、出货概率表格、秘书舰双栏选择器和公式表格。当前版本仍有三处视觉与交互不一致：

- 出货概率表的内容行偏高，与「持有」页面的装备单行密度不一致；
- 资源输入同时显示图标和「燃料、弹药、钢材、铝土」文字，信息重复；
- 目标装备仍使用类型下拉框和卡片列表，类型以 `#1` 等内部编号显示，未复用已经确认的秘书舰双栏交互。

本次只调整装备开发页面的 UI 投影和选择器交互，不修改概率、配方、兼容目标或排序算法。

## 目标

- 出货概率表与「持有」装备单行使用相同的基础密度参数。
- 资源输入依靠图标识别资源类型，不再重复显示资源名称。
- 目标装备选择改为秘书舰同款左右双栏结构。
- 装备类型一律显示游戏主数据中的名称，不显示内部类型编号。
- 保留搜索、多目标选择、跨类型已选状态和不兼容装备禁用逻辑。

## 出货概率表

### 密度参数

出货概率表以 `FrozenDataTable` 和「持有」装备表的普通单行为视觉基准：

| 项目 | 参数 |
| --- | --- |
| 表头高度 | 34 px |
| 普通内容行高度 | 44 px |
| 内容字号 | 12 px |
| 装备名称字重 | `FontWeight.w800` |
| 类型文字字重 | `FontWeight.w700` |
| 概率文字字重 | `FontWeight.w900` |
| 图标容器 | 25 × 25 px |
| 图标图片 | 23 × 23 px |
| 单元格水平内边距 | 8 px |
| 图标与名称间距 | 7 px |

装备名称保持单行显示。窄屏下保留横向滚动，不通过压小字号换取宽度。表格仍至少铺满卡片可用宽度，不能恢复右侧空白。

### 列与排序

列结构保持为「装备、类型、最终概率」。类型继续读取 `GameState.masterSlotItemTypes`，主数据缺失时显示 `—`。最终概率默认降序，点击表头切换升序；目标装备继续固定在普通装备之前。

## 资源输入

4 个输入框继续使用既有资源图片：

- 燃料：`assets/images/material/01.png`；
- 弹药：`assets/images/material/02.png`；
- 钢材：`assets/images/material/03.png`；
- 铝土：`assets/images/material/04.png`。

输入框删除可见的资源名称和浮动标签，只保留前置图标与数值。资源名称保留在语义标签和 Tooltip 中，确保辅助功能和长按提示仍能识别资源类型。数值范围、输入校验和即时回算逻辑不变。

## 目标装备双栏选择器

### 页面结构

点击「选择目标装备」后，打开与秘书舰选择器相同风格的居中 `Dialog`，不再使用底部面板和类型下拉框。

对话框由以下区域组成：

1. 顶栏：标题、已选数量、圆形搜索按钮和关闭按钮；
2. 左栏：装备类型名称；
3. 右栏：当前类型下的装备列表。

左右栏使用与秘书舰选择器相同的宽度比例、背景层级、分隔线、选中高亮和滚动方式。左栏固定，右栏独立滚动。

### 类型文字

左栏按数据集中实际出现的 `typeId` 建立稳定列表，但显示 `GameState.masterSlotItemTypes` 中的类型名称，例如「小口径主炮」「机枪」「鱼雷」。界面不显示 `#1`、`#21` 等内部编号。

主数据缺失的类型统一归入「其他」，不得回退为 `#typeId`。排序以 `typeId` 保持稳定，不使用本地化文字排序。

### 装备列表

右栏每项只显示以下内容：

- 23 px 装备类型图标；
- 装备名称；
- 右侧选择状态图标。

删除 `ID 1 · #1` 等副标题，不显示装备 ID 或类型代码。长名称使用单行省略，完整名称通过语义标签保留。

### 多选交互

- 点击可用装备后切换选中状态，对话框保持打开；
- 已选装备显示高亮背景和勾选图标；
- 再次点击已选装备可取消；
- 切换左栏类型时，其他类型中的已选装备保持不变；
- 已选数量即时更新；
- 不可与当前目标共同开发的装备保持可见但禁用；
- 点击关闭按钮、遮罩或系统返回键关闭对话框，并保留当前已经完成的选择。

多选继续直接写入 `EquipmentDevelopmentController.targets`，不增加临时确认状态或额外「确定」按钮。

### 搜索

圆形搜索按钮和独立搜索弹窗保持不变。确认搜索后：

- 右栏只显示当前左栏类型中匹配名称或装备 ID 的项目；
- 搜索词以紧凑标签显示，并可一键清除；
- 切换类型不会清除搜索词；
- 搜索无结果时只在右栏显示局部空状态，左栏仍可切换。

搜索允许输入 ID 作为定位条件，但搜索结果本身不显示 ID。

## 组件边界

- `development_output_table.dart`：负责紧凑表格参数与概率排序交互；
- `equipment_development_page.dart`：负责无文字资源输入；
- `development_equipment_picker.dart`：负责目标装备双栏多选对话框；
- `equipment_development_controller.dart`：继续提供类型名称、筛选、多目标兼容和搜索状态。

秘书舰选择器的颜色、尺寸和双栏结构作为样式基准。可以提取小型共享样式常量，但不为本次需求重构成通用选择器框架，避免扩大范围。

## 测试要求

### Widget 测试

- 出货概率表表头高度为 34 px，普通行高度为 44 px；
- 装备名称字号为 12 px，图标图片为 23 × 23 px；
- 表格仍铺满卡片可用宽度；
- 资源输入没有可见的资源名称，但保留图标、数值和语义标签；
- 点击「选择目标装备」打开双栏对话框，不再出现类型下拉框；
- 左栏显示类型文字，不显示 `#typeId`；
- 右栏不显示装备 ID 和类型代码；
- 选择装备后对话框保持打开，已选数量和勾选状态即时更新；
- 切换类型后保留其他类型的已选装备；
- 搜索、禁用不兼容项和关闭后保留选择继续工作。

### 回归验证

- 运行全部 `test/development` 测试；
- 对 `lib/src/development` 和 `test/development` 运行静态分析；
- 通过热重启验证，不构建 Debug APK。

## 验收标准

- 出货概率表的视觉密度与「持有」装备普通单行一致；
- 4 个资源框只显示图标和数值；
- 目标装备选择器与秘书舰选择器保持同一套双栏视觉语言；
- 类型显示可读文字，装备项不再暴露 ID 或类型代码；
- 用户可以跨类型连续选择多个目标装备，关闭对话框后选择仍然生效；
- 概率计算、配方生成、目标兼容和排序行为没有变化。
