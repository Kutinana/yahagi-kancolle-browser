# 未持有舰娘提醒说明设计

## 目标

在“持有一览”的未持有舰娘视图中，直接说明勾选状态与新船提醒的关系，避免用户误以为勾选代表开启提醒。

## 界面方案

- 说明文字放在舰种筛选栏正下方、舰娘列表上方。
- 简体中文文案为：“获得未勾选的舰娘时，将正常提醒并震动；勾选的舰娘则不会提醒。”
- 使用小号、低强调度的浅灰色文字，不与筛选结果和黄色数字争夺视觉焦点。
- 窄屏下允许自然换行，不截断文字，也不引入横向滚动。
- 仅在“未持有 → 舰娘”视图显示；切换到“持有”或“未持有 → 装备”时不显示。

## 本地化

- 简体中文：获得未勾选的舰娘时，将正常提醒并震动；勾选的舰娘则不会提醒。
- 繁体中文：獲得未勾選的艦娘時，將正常提醒並震動；勾選的艦娘則不會提醒。
- 日文：未選択の艦娘を入手すると通常どおり通知と振動を行い、選択した艦娘は通知しません。

## 验证

- 组件测试确认说明文字仅出现在未持有舰娘视图。
- 组件测试确认简体中文文案及低强调度文字样式。
- 在窄屏尺寸下渲染，确认文字可换行且无溢出。
- 运行持有一览、本地化相关测试与静态分析。
