# 秘书舰适用范围标签设计

## 目标

恢复开发池原有的完整秘书舰说明。二级选择器仍按“系别 / 具体开发池”双栏展示，右栏不再只显示“意”“意驱”等简称，而显示“意（利托里奥、罗马、扎拉）”“意驱（西北风级）”等完整适用范围。

## 数据设计

开发池快照继续保存现有匹配条件，并新增每种语言的 `descriptions` 字段。同步脚本从上游固定提交中的舰种、舰级、舰娘名称表生成描述，避免 Flutter UI 硬编码规则或翻译。

描述顺序与上游规则一致：舰种、舰级、指定舰名、排除舰、直接指定舰 ID。列表在中文与日文中使用顿号，在英文中使用逗号加空格。

## 显示设计

- 双栏对话框左栏保持开发系别。
- 右栏显示“简称（适用范围）”。
- 顶部已选秘书舰类型同样显示完整池名和适用范围。
- 说明为空时只显示原池名，不生成空括号。
- 超长文本保持单行省略，避免破坏现有对话框布局。

## 兼容与验证

快照 schema 版本保持为 1，新字段按必填多语言字段解析；现有测试夹具补齐该字段。测试覆盖描述生成、本地化选择、右栏完整标签与超长文本布局。
