# 首页陆基简报设计

## 目标

在首页信息面板中，将「陆基简报」作为独立胶囊插入「编队简报」下方。用户无需打开海域页面，即可查看各海域基地航空队的配置、行动状态、制空、航程、搭载数、基地 HP 和中队疲劳。

本次只实现首页胶囊，不实现航空队详情页或弹层。

## 参考与约束

- 信息结构参考 POI 的基地航空队简报，但视觉继续使用 Yahagi 的深蓝金色主题。
- 飞机立绘、制空、航程、行动状态和 4 个中队槽位按航空队逐行展示。
- 不增加「出击制空合计」「防空制空合计」「最短航程」「总体状态」等跨队汇总指标。
- 基地 HP 和疲劳效果复用编队简报的视觉规范，但使用陆航自己的数据语义。
- 首页胶囊继续支持现有卡片排序、折叠和隐藏设置。

## 首页布局

### 卡片位置

默认顺序如下：

1. 战斗简报
2. 编队简报
3. 陆基简报
4. 远征简报
5. 入渠简报
6. 建造简报
7. 任务简报
8. 出击前检查

### 卡片标题

- 标题：`陆基简报`
- 图标：飞机图标
- 右侧：海域切换器
- 海域切换项使用 `api_area_id`，例如 `6`、`62`。
- 默认选中最近一次刷新且包含基地航空队的海域；没有历史选择时选中排序后的第一个海域。

### 海域标题

海域切换器下方显示：

- `[海域 ID] 海域名称`
- 该海域的航空队数量

海域名称优先使用主数据；缺失时显示 `[海域 ID]`，不阻止航空队行渲染。

### 航空队行

每支航空队占一行，包含：

- 左侧飞机立绘，使用第一件有效装备的 `item_up` 游戏资源。
- 立绘上覆盖航空队名称。
- 立绘下部显示 `制空 {min}` 或 `制空 {min}+`，以及有效航程。
- 中部显示行动状态：待机、出击、防空、休息或退避。
- 行动状态下方显示基地 HP 条和 `当前值/最大值`。
- 右侧显示 4 个中队槽位，包括装备类型图标、当前搭载数和槽位状态。

航空队行保留点击反馈，但本次不打开详情页；不显示「点击航空队查看装备详情」提示。

## 基地 HP

### 数据来源

基地空袭发生在 `api_req_map/start` 或 `api_req_map/next` 返回的 `api_destruction_battle` 中：

- `api_f_maxhps`：基地最大 HP。
- `api_f_nowhps`：空袭结算前 HP。
- `api_air_base_attack.api_stage3.api_fdam`：本次基地伤害。

当前 HP 为：

```text
currentHp = clamp(api_f_nowhps - api_fdam, 0, api_f_maxhps)
```

返回母港后，空袭期间的临时 HP 数据失效。首页在没有临时数据时显示 `200/200`，与 POI 的默认展示一致。

### 视觉规则

HP 动画只包围飞机立绘，不作用于整条航空队胶囊：

| HP 比例 | 颜色 | 动画 |
|---|---|---|
| `> 75%` | 绿色 | 静态 |
| `> 50%` 且 `≤ 75%` | 黄色 | 慢速脉冲 |
| `> 25%` 且 `≤ 50%` | 橙色 | 中速脉冲 |
| `> 0%` 且 `≤ 25%` | 红色 | 快速脉冲和立绘色罩 |
| `0%` | 灰色 | 静态 |

立绘外框和行动状态下方 HP 条使用同一比例、颜色与数值。复用 `ShipHpFrame`、`DamagePulseBuilder` 和 `shipHpBarColor` 的视觉算法，不复用舰娘 ID 语义。

## 中队状态与疲劳

每个中队保存以下字段：

- `api_squadron_id`
- `api_state`
- `api_slotid`
- `api_count`
- `api_max_count`
- `api_cond`

显示规则：

- `api_state == 0`：空槽。
- `api_state == 2`：配置转换中，图标降低透明度并显示转换标记。
- `api_count < api_max_count`：搭载数和图标显示缺机警示。
- `api_cond == 2`：对应中队图标显示橙色疲劳光晕。
- `api_cond > 2`：对应中队图标显示红色疲劳光晕。

航空队立绘只显示最严重的疲劳表情：

- 全部中队正常：不显示表情。
- 存在黄疲劳且没有红疲劳：立绘右上角显示黄脸。
- 存在红疲劳：立绘右上角显示红脸。

黄脸和红脸复用 `ShipMoraleMark` 的视觉形式与位置，但不使用舰娘的 `cond >= 50` 刷闪判断。基地损伤本身不显示疲劳表情。

## 制空与航程

### 制空

单支航空队的制空计算与 POI `getTyku` 保持一致：

- 使用实际搭载数。
- 纳入装备对空、适用的改修补正和熟练度区间。
- 出击状态对局地战斗机使用 `1.5 × 迎击` 补正。
- 防空状态使用 `迎击 + 2 × 对爆` 补正。
- 侦察机补正取队内最高值，不叠加。

当最小值等于最大值时显示单值；存在熟练度区间时显示 `{min}+`。

### 航程

优先使用接口返回的：

```text
api_distance.api_base + api_distance.api_bonus
```

没有航程数据时显示 `—`，不自行猜测。

## 数据刷新

### 全量刷新

`api_get_member/mapinfo` 返回完整 `api_air_base`，用于建立或替换各海域基地航空队数据，包括距离和 4 个中队状态。

### 局部刷新

捕获并处理以下接口：

- `api_req_air_corps/set_plane`
- `api_req_air_corps/change_deployment_base`
- `api_req_air_corps/set_action`
- `api_req_air_corps/supply`
- `api_req_air_corps/change_name`

局部响应只更新响应中存在的航空队或中队字段，不能清空未返回的其他槽位。

疲劳随时间在服务器端恢复。应用不推算未公开的精确恢复值，只在游戏返回新的 `api_plane_info` 后更新显示。若「航空特别增加食」使用接口尚无真实样本，暂不猜测其路径；下一次 `mapinfo` 仍可校准状态。

## 数据模型

扩展 `LandBaseState`：

- 保留 `areaId`、`baseId`、`name`、`actionKind`、`maxHp`、`currentHp` 和 `lastRaidDamage`。
- 新增 `distanceBase`、`distanceBonus`。
- 新增不可变的 `List<LandBaseSquadronState>`。

新增 `LandBaseSquadronState`：

- `squadronId`
- `state`
- `slotItemId`
- `currentCount`
- `maxCount`
- `condition`

`slotItemId` 是玩家装备实例 ID。制空和立绘解析需要通过 `GameState.slotItems` 找到装备主数据 ID，再通过 `GameState.masterSlotItems` 获取属性和资源版本。

## 兼容与错误处理

- 旧缓存没有新增字段时使用空中队列表和空航程，不影响反序列化。
- 未捕获 `mapinfo` 时，卡片显示无数据状态。
- 装备实例或主数据缺失时，槽位仍显示搭载数，并使用未知装备图标。
- 游戏资源加载失败时显示装备类型占位图，不显示破损图片控件。
- API 数组中的无效项按槽位跳过，不使整张卡片崩溃。
- 返回母港只清理临时 HP，不清理海域、行动状态、航程和中队配置。

## 测试范围

- `mapinfo` 解析多个海域、多个航空队和 4 个中队。
- 换装、跨基地换装、行动切换、补给和改名的局部更新。
- 基地空袭 HP 计算以及返回母港后的临时 HP 清理。
- 缓存序列化、旧缓存兼容和新增字段往返。
- 出击与防空制空公式、熟练度区间和航程。
- 卡片默认位于编队简报下方，并支持排序、折叠和隐藏。
- 正常、轻损、中损、重损、黄疲劳、红疲劳、缺机、配置转换中和缺失数据的组件测试。
- HP 外框只包围立绘；损伤不显示疲劳脸；疲劳脸位于立绘右上角。

## 非目标

- 不实现航空队详情页或弹层。
- 不实现跨航空队制空合计等汇总指标。
- 不预测服务器端疲劳恢复倒计时。
- 不发送换装、补给、切换行动等游戏操作。
- 不修改 POI 参考源码。
